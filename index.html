MyPackLauncher

개인 서버용 Minecraft: Java Edition 런처 프로젝트입니다.

주요 기능

  • 서버 매니페스트를 이용한 게임 파일 무결성 검사 및 동기화
  • Microsoft OAuth 디바이스 코드 방식 로그인
  • 정품 Minecraft: Java Edition 보유 여부 및 프로필 확인
  • Vanilla 1.21.11 실행 지원

인증과 보안

런처는 Microsoft의 공식 OAuth 흐름을 사용합니다. 사용자의 Microsoft 비밀번호를 요청하거나 저장하지 않으며, 인증 토큰은 Windows 사용자 계정에 귀속되는 암호화 기능으로 로컬 컴퓨터에만 보관합니다.

라이선스 준수

정품 게임 계정만 사용할 수 있도록 Minecraft 서비스에서 소유권과 프로필을 확인합니다. 보안, 인증 또는 라이선스 검사를 우회하지 않으며 안전 기능을 비활성화하지 않습니다.

데이터 처리

별도의 사용자 계정 데이터베이스를 운영하지 않습니다. 로그인 처리는 Microsoft, Xbox Live 및 Minecraft 서비스에서 수행되며 런처 서버는 사용자 비밀번호나 인증 토큰을 수집하지 않습니다.
